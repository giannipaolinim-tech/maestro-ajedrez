# Maestro — aperturas de ajedrez

Lecciones, práctica guiada y exámenes con repetición espaciada para repertorios de aperturas.

- `npm run build` valida el repertorio y genera `dist/` (la app es `dist/index.html`, un único archivo).
- `npm run serve` arma y sirve la PWA en http://localhost:8080/ para probarla.
- Cada push a `main` la publica en GitHub Pages (`.github/workflows/pages.yml`). Desde ahí se instala en Android con Chrome → «Instalar app», funciona sin conexión y se actualiza sola al abrirla con internet.
- Contexto completo del proyecto para Claude Code: `CLAUDE.md`.
